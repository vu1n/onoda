# Frozen pilot design, 2026-11-13
This is an isolated feasibility pilot, not an Onoda integration or novel circuit claim. GPT-2 small on English indirect-object identification. Test reference: Wang et al. 2022, https://arxiv.org/abs/2211.00593. TorchLens tracing is separately validated; direct PyTorch hooks can implement causal head-output patches if needed.

Use disjoint prompt templates for train, validation and test; names all single GPT-2 tokens. Clean: IO name A, repeated subject B. Primary corrupt: repeated subject A (reverse answer). Alternate held-out corrupt: replace repeated subject with a third name C (ABC control). Match token lengths; reject ambiguous alignments rather than silently pad. Report raw clean/corrupt logit difference before comparing patch fractions.

Candidate intervention: patch outputs of three attention heads (all positions) from clean into corrupt runs; reverse patch measures necessity. Fixed known IOI name mover heads (9,6), (9,9), (10,0); this prior is explicit, not learned. Random uses 16 three-head subsets per seed over all 144 heads; three seeds. Select by train average normalized recovery; validation reported without retuning, locked test used once per chosen candidate. Identity and all-head patches are controls; input corruption and layer replacements are not purported discoveries. Count forward evaluations including unsuccessful candidates. Report recovery of clean-corrupt logit-gap, absolute gaps, size, CPU wall time and per-example outcomes. No causal generalization beyond this specific model/task/intervention distribution.

GEPA only counts as run if actual reflective proposal generation and evaluator feedback occur. No paid API permitted. If the environment lacks a practical local reflector, deliver validated fixed/random baselines and flag GEPA as NOT RUN, not a disguised deterministic heuristic. No independent hypothesis about GEPA superiority from a missing arm.
