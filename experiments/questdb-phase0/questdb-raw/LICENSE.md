# Licence of the files in this folder

These files are unmodified copies from the QUEST database,
https://github.com/pfloos/QUESTDB at commit
`460482bcc6231dab41fe32188dc43959a7c2bdaa` (2026-07-30), paths preserved:

- `geometries/xyz/*.xyz`: CC3(Full)/aug-cc-pVTZ geometries (angstrom).
- `data/cas/json/*_mrpt.json`: active-space tables with CASSCF, CASPT2,
  NEVPT2 and CASPT3 vertical excitation energies (eV, aug-cc-pVTZ).
